manim-web (by maloyan)
This project allows you to create programmatic mathematical animations with a Python-like API directly in the browser using WebGL. It has a dedicated documentation site
https://maloyan.github.io/manim-web/
.
GitHub Repository:
https://github.com/maloyan/manim-web
Documentation Site:
https://maloyan.github.io/manim-web/
Key features:
Renders in real-time at 60fps, no server or video encoding needed.
Supports geometry, text/LaTeX, graphing, 3D scenes, and core animations.
Examples are available on the documentation site.
